# text-data-utils
* Small, well-tested Python package of reusable text preprocessing and data-validation utilities (cleaning, tokenization helpers, split functions, schema checks) designed to be dropped into ML pipelines. Includes CLI examples, unit tests, and GitHub Actions to run tests on push.*

*  Problem: provide reliable text data cleaning and validation helpers for ML workflows. Deliverables: installable package (pyproject.toml), core functions with examples, CLI demo, unit tests, and CI.*

 *    Quick start: pip install -e . → python -m text_data_utils.clean --input data/reviews.csv.*
